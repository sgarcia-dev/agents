# ChatGPT website: project management and source lifecycle

Load `~/agents/skills/chatgpt-browser/SKILL.md`. Writes require authorization for the exact project, chats and files. Inventory before mutation; serialize account writes; independently reload after them. Select target-local controls, not a duplicate title elsewhere on the page.

## Discover and create

- `https://chatgpt.com/projects` is the full observed project **directory**; the home sidebar is only a subset. Rows sit in `[data-testid='project-directory-scroll-root'] tr[role=row][data-page-table-selectable-row='true']` and carry `[data-testid='project-folder-icon']`. Filters are `All`, `Created by you`, `Shared with you`. Rows lack an href: click an exact row and read the resulting `/g/<project>/project` pathname rather than guessing an ID. Measure scroll range and look for pagination before claiming directory coverage.
- Sidebar `button[aria-label='New project']` opens a form with `#project-name` and `Create project`. Read the memory option instead of changing it silently. Verify `/g/<project>/project`, exact heading and `No chats yet` after creation. A project home exposes `Chats` and `Sources`; `main a[href*='/c/']` cards can be capped at around ten, so cards are not a full conversation denominator.
- For inventory beyond cards, an observed same-origin read-only endpoint was `GET /backend-api/gizmos/<project_id>/conversations`, with session auth and `cursor` pagination until null. Treat endpoint and auth shape as unversioned observations; inspect network/UI before use, never log tokens, and do not fabricate IDs or circumvent access. To assert **zero**, require HTTP 200 with `items:[]`, `cursor:null`, matching `No chats yet`/zero in-main cards, and a positive known-project control fetch in the same session. A failed/unauthorized request is not empty inventory.

## Move and remove conversations

1. Freeze exact chat IDs/hrefs and source project membership **before** a batch. Sidebar pinned links precede Chats and mutation can reorder recent entries. The Chats-section `a[href^='/c/']` and its sibling `button[aria-label='Open conversation options for <title>']` must be bound to the **same row**; titles can duplicate.
2. For a move, choose that row's `Move to project` and the exact target project item. Check the destination project card for the same ID, then independently reload and check again. For a project conversation, choose its own `Remove from project` to take it out **without deleting it**; verify absence from project and continued existence in history. Never use Archive or Delete as a substitute. A header More route and project-card options have been seen, but exact sidebar-row move and project conversation remove are the tested round trip.
3. In parallel **read-only** classification, compare final URL, hydrated document title, `conversation-options-<ID>` and actual turn text per ID before a writer acts. A prior four-worker run cross-associated one tab's content with another ID. Serialize all moves/deletes; on timeout read settled membership before retrying.

## Sources: add, verify, remove

1. Open the exact project, select `Sources` and require `aria-selected=true` (a physical click may be needed). Inventory existing rows. `Add sources` showed Upload, Text input, Google Drive, Slack, and a drag target. Only local file input and Text input were tested; do not initiate external connections without scope.
2. For an authorized local file, target the **Add sources dialog's** `input[aria-label='Upload'][type=file]`, not the composer's attachment input. The adapter may use a file-input API or a file-chooser API. Upload one at a time, wait for processing, reload/reopen Sources and compare **exact displayed filename and row count**. A live card or early empty list is insufficient. Duplicate uploads may acquire `(1)` suffixes; do not silently call them the original filename. For Text input, use `#project-text-title`, `#project-text-content`, then Save; it produced a `.txt` source in the tested UI.
3. To remove, bind `button[aria-label='Source actions']` to its nearest `div[class*='group/file-row']` with the exact intended filename, choose Delete, reload and compare remaining inventory. To prove an empty project require `Give ChatGPT more context` and zero Source actions. A Delete click once left a fixture after reload, so readback is mandatory.
4. Do not send a model prompt merely to verify routine uploads. If the owner specifically asks about retrieval, check an explicit model in that project's composer and use an authorized, non-sensitive test question. A project-only-memory project once disabled Work and exposed only a `Latest` Chat label, so a card does not prove GPT-6 retrieval. A separate default-memory project returned both synthetic fixture values with an explicit model; this is a bounded test, not a guarantee for all projects.

Source filename extraction: read extension-bearing aria labels **within the Sources panel**, cross-check each file-row's first text line and require distinct-name count to equal row count. A leaf/button fallback previously repeated one filename for every row. Never store project source content as an inventory side effect. Leave unrelated rows untouched.
