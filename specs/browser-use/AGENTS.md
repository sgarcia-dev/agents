# Browser Use Spec Scope

Read `spec.md` first for the portable contract, then `STATE.md` for current status, `DECISIONS.md` for choices, and `SOURCES.md` for evidence. The historical Jev bundle is linked from `SOURCES.md`; do not treat its dated observations or the user reports as current policy.

The nested `artifacts/investigations/` tree has two user-approved, bounded exceptions: the existing September 24 Jev bundle and the September 25 bundle of exactly six Claude-generated parallel-browser reports. Preserve source bytes and check links. Neither exception permits further generated reports here without a fresh placement decision. New artifacts normally follow the workspace's root or repository-project artifact convention.

This is a coworker-visible Git repository. Never add secrets or private material here. Browser use, existing-profile access, and native desktop computer use are separate capabilities with separate permissions and tests. Do not edit more than one harness's native configuration in a single session.
