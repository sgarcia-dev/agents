# Claude Code Approved Divergences

## Current Decisions

| `role-dispatch` is not mapped to any native Claude Code skill or command. | User-approved 2026-09-22. | The skill exists for harnesses that expose many models per role. | Superseding the row above, later the same day: `model: opus` with both Opus 5 and Sonnet 5 pinned to medium. The user judged medium the value sweet spot for both models and wanted the stronger model at the root seat rather than a cheaper one. | 2026-09-22 |
| `task-explore` was set to `claude-haiku-4-5-20251001` earlier in the day; the user rejected that and moved it to `claude-sonnet-5` at medium, matching `task-execute`. Read-only discovery packets still feed the root's reasoning, so the user did not want a weaker model there. | 2026-09-22 |
| Earlier in the day the global `effortLevel: xhigh` was described as "what an Opus 5 session picks up." True at the time, and it meant Opus sessions were starting at xhigh unnoticed. Opus 5 now has its own medium override, so that fallback reaches neither model the user runs. | 2026-09-22 |
| This adapter briefly claimed that `/effort` always writes the global default, stated as a flat rule in a drift check. Overgeneralized from one command's output. Evidence is narrower: one `/effort medium` call in the same session returned "Kept effort level as xhigh" and changed nothing, while a later bare `/effort` reported saving a default. Which form persists is not established here. The `--effort` CLI flag is separately documented as current-session-only. | 2026-09-22 |
